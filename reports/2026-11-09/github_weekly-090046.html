2.gputaskman：面向 Windows、Linux 与 WSL 的 GPU 任务管理器★★★★★

⭐ 1.0k · Python · GitHub

由知名开发者 Scott Hanselman 发起，提供类似 htop 的终端界面，按进程展示显存占用、GPU 活动，并关联已加载的运行时、模型文件与 LLM 的 KV 缓存明细。它试图回答「15GB 显存到底被谁吃了」这一本地推理与微调中的高频问题，支持 Windows 上的 NVIDIA/AMD 以及 Linux、WSL 和 Apple Silicon。适合本地跑模型、排查显存瓶颈的开发者，项目处于早期但方向明确。

为什么重要：本地 LLM 推理的显存归因长期缺少趁手工具，该项目直击痛点且跨平台覆盖完整。

⭐ 1.4k · HTML · GitHub

为什么重要：它把「token 效率」作为 3D 库的一等设计目标，为 LLM 生成 CAD 内容提供了务实路径。
