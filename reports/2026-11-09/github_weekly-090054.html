2.kota：在 GNOME 顶栏统一监控各家 AI 服务用量与额度★★★

⭐ 57 · Rust · GitHub

kota 用 Rust 编写，把 Claude、Codex、Gemini、GitHub Copilot 及各类 API 余额的用量限制直接显示在 GNOME 顶部面板，含百分比、环形进度、重置时间、按当前速率推算的耗尽预测，以及最近 24 小时 token 曲线。它还能列出正在运行的 AI 智能体进程及其端口、内存占用，并支持一键停止。对同时订阅多家 AI 服务的开发者来说，这是一个轻量但实用的桌面侧监控入口。

为什么重要：多模型订阅时代的「用量仪表盘」需求真实存在，且以 GNOME 扩展形式落地，集成成本低。
